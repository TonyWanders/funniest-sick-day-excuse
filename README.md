A program that writes one funny sick-day excuse to `/output/entry.txt`,
for the make.fun competition
[The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

Run it with Python 3:

```
python3 main.py
```

It writes the excuse below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The excuse is 120 characters, inside the 1 to 200 gate.

## The excuse

```
Sorry, can't come in, my toddler superglued my car keys to the fridge and now the dog is guarding them like rent is due.
```
